# LISEA

Personal website and portfolio for an independent video editor.

## Frontend

- React + TypeScript + Vite
- GSAP for scroll-linked motion
- Three.js for the continuous 3D film strip
- PostgreSQL and a Node.js backend will be added during the local development phase

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The Vite base path is configured for the GitHub repository name (`/LISEA/`). Update it if the deployment target changes.
